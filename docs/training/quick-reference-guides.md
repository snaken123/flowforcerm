# FRONT DESK STAFF — Quick Reference

## Daily Opening Checklist
- [ ] Log in at app.northsouth.com.ph
- [ ] Check Dashboard → **Expiring Soon** (contact athletes expiring in 7 days)
- [ ] Verify kiosk tablet is on and logged in at `/kiosk`
- [ ] Check Today's Check-ins count on Dashboard

## Check In an Athlete
1. Go to **Staff Check-in** (sidebar)
2. Type athlete name → click **Check In**
3. If duplicate warning appears → confirm if intentional

## Add a New Athlete
1. **Athletes** → **Add Athlete**
2. Fill First Name, Last Name, Email
3. Save → member number auto-assigned (NS-XXXXX)

## Assign a Membership
1. **Athletes** → search → **View**
2. Click **Assign Membership**
3. Select Service → Package → Pricing → Payment → Save

## Log a Payment
1. Athlete detail page → **Log Payment**
2. Choose subscription → enter amount, date, method → Save

## Record a Store Sale
1. **Store** → click items to add to cart
2. Set payment mode (select sub-type if Bank Transfer / eWallet)
3. Click **Record Sale**

## Common Shortcuts
| Task | Path |
|---|---|
| Find an athlete | Athletes page → search box |
| Check today's attendance | Dashboard → Today's Check-ins |
| View expiring memberships | Dashboard → Expiring Soon |
| Print/export revenue | Reports → daily or monthly → CSV or PDF |

## Payment Methods
Cash · GCash · Credit Card · Bank Transfer (BDO / BPI) · eWallet (GCash / Maya) · Class Pass

## Member Statuses
- **ACTIVE** — training, all OK
- **INACTIVE** — not yet activated or lapsed
- **FROZEN** — memberships on hold
- **CANCELLED** — left the gym

# GYM OWNER / ADMIN — Quick Reference

## Most Common Tasks

| Task | Path |
|---|---|
| Add a new service/program | Memberships → Add Service |
| Add a package to a service | Memberships → service → Add package |
| Add a class to the schedule | Schedule → Add Class |
| Freeze an athlete's memberships | Athlete detail → Freeze All |
| Delete a membership | Athlete detail → subscription → Delete |
| Change kiosk/store password | Settings → update password |
| View all subscriptions | Subscriptions → filter by status |
| Check audit trail | Activity Logs |
| Send a broadcast email | Communications → New Broadcast |
| Generate revenue report | Reports → select date/month |

## Admin-Only Actions
- Delete athletes (2-step: reason + password)
- Freeze/unfreeze memberships (requires password)
- Delete memberships (blocked if bookings exist)
- Add/edit employees
- Add/edit services and packages
- Access Reports, Logs, Settings, Web Integration

## Membership Discount Reasons
Employee Price · Family/Friend Discount · Loyalty Discount · Promotional Rate · Complimentary · Bundle Deal

## Subscription Edit Reasons
Admin entry error · Billing correction · Medical/injury extension · Freeze adjustment · Membership transfer · Customer request · Promotional extension

## Schedule Edit Scopes
- **Just this session** — one-time override
- **This and succeeding** — cuts and restarts series
- **All sessions** — edits everything

## Emergency: Restore a Frozen Athlete
1. Athlete detail → **Remove Freeze**
2. Enter reason + admin password → Confirm

# COACH — Quick Reference

## Your Dashboard
- Log in → **Dashboard** shows today's classes you are assigned to
- Each class shows booked athletes and their check-in status

## Viewing the Schedule
- **Schedule** (sidebar) shows only classes where you are assigned as coach
- Use **Week** or **Day** view
- Click any class slot to see the attendance list

## Taking Attendance
1. Click the class slot on the schedule
2. Check the box next to each athlete who attended
3. Status changes CONFIRMED → ATTENDED automatically

## Adding an Athlete to Your Class
1. Click the class slot → **Add Athlete** tab
2. Search by name → select the athlete
3. They are booked if they have an eligible subscription

## What You Cannot Do
- Add or edit schedule slots (admin only)
- View other coaches' classes (only your own)
- Access athlete financial data
- Access Reports, Settings, Communications

# ATHLETE / MEMBER — Quick Reference

## Your 4 Pages

| Page | What to Do There |
|---|---|
| **Athlete ID** | Show QR code at the kiosk to check in |
| **My Profile** | Update phone, address, emergency contact |
| **My Schedule** | View upcoming classes and book sessions |
| **My Billing** | Check sessions remaining and payment history |

## How to Check In
1. Open GymRM on your phone → **Athlete ID**
2. Show the QR code to the scanner at the gym entrance
3. Wait for the success screen

## Add to Home Screen (Faster Access)
- **iPhone:** Tap Share → Add to Home Screen
- **Android:** Tap Menu (⋮) → Add to Home Screen

## Your Member Number
Format: **NS-XXXXX** (shown on Athlete ID page)
Memorize it as a backup if you don't have your phone.

## Can't Log In?
- Forgot password → tap "Forgot password?" on login page → check your email
- Never received activation email → contact front desk

# STORE OPERATOR — Quick Reference

## Recording a Sale
1. Log in → Store page opens automatically
2. Tap items to add to cart
3. Select payment mode (**must** select sub-type for Bank Transfer / eWallet)
4. Tap **Record Sale**

## Current Items
| Item | Price | Stock |
|---|---|---|
| Gatorade | ₱50 | Check screen |
| Water 1 liter | ₱25 | Check screen |
| Kopiko | ₱0 | 0 (out of stock) |
| Merchandise | Varies | Check screen |

## Payment Modes
- Cash → select Cash
- GCash → select eWallet → GCash
- Maya → select eWallet → Maya
- BDO → select Bank Transfer → BDO
- BPI → select Bank Transfer → BPI
- Credit Card → select Credit Card

## If an Item is Out of Stock
- It appears greyed out and cannot be added to the cart
- Contact admin to restock via Inventory → Adjustment

## What You Cannot Access
- Inventory management (admin/staff only)
- Athlete financial data
- Reports
- Settings
